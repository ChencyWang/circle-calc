##circle-calc  
by bilibili [@Chency_Wang_lzy](https://space.bilibili.com/3706924453333179)  
- Function: specially used to calculate the volume and surface area of circles, solid figures and plane figures.  
Function function:  
1.`CircleAreaCalc()` : Calculate the area of a circle  
```cpp
double CircleAreaCalc(double radius, double PI) {
	return PI * radius * radius;
}
```
2.`CirclePerimeterCalc()` : Calculate the circumference of a circle  
```cpp
double CirclePerimeterCalc(double radius, double PI) {
	return PI * radius * 2;
}
```
